# Documentation History

This directory keeps information that is useful for audit and context but is
not required for current development.

- `ROADMAP_COMPLETED.md`: completed milestones and original acceptance criteria.
- `DECISIONS_001-031.md`: full append-only decision log, including superseded
  prototype decisions.
- `STATUS_2026-06-22_INT-002.md`: handoff after the build-pipeline integration.
- `TSSCRIPTS_PILOT.md`: external TsScripts pilot commands and observations.
- `SPEC_RESEARCH.md`: retired Babel/Bun research and the completed implementation
  sequence.
- `HOK-Integration-Plan.md`: Unity C# adapter landing plan and its verified
  measurements (V2/V3/V4 macro-generation paths). Superseded as a live plan; the
  effective checklist lives outside this repo. Kept for the measurement evidence.
- `TsScripts-Integration-Plan.md`: TS build wiring plan based on the earlier
  on-disk projection scheme. Fully superseded by projected compilation
  (`tsifdef build`); see `SPEC.md` §8/§13 and
  `docs/projected-compilation-plan.md`.

Start with `SPEC.md`, `docs/STATUS.md`, `docs/ROADMAP.md`, and
`docs/DECISIONS.md`. Read files here only when their historical detail is
needed.
